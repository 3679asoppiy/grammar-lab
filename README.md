# Grammar Lab — 英語文法トレーニング

HTML / CSS / JavaScript で作った、タイピング式の英語文法学習アプリです。

## できること

- 日本語 → 英語、英語 → 日本語、ミックス形式で出題
- 選択肢なし。回答を自分でタイピング
- **AIによる自動採点は行わず、模範解答を見て自分で採点**
- 英語・日本語ともに、1問につき複数の模範解答・別解を登録可能（1行に1つ）
- 解答表示後に「正解」「不正解」「要復習」を自分で選択
- 不正解・要復習を復習リストに登録し、苦手な問題から優先して再出題
- 同じ問題に連続2回正解すると復習リストから除外
- 学習した日・回答数・自己採点結果をカレンダーに記録
- 文法データと学習履歴を JSON でバックアップ・復元
- スマホ・タブレット・PCに対応

## 使い方

`index.html` をブラウザで開いてください。最初からサンプル文法が4件登録されています。

1. ホームから出題方向を選び、テストを開始します。
2. 回答を入力して「解答を表示する」を押します。
3. 表示された模範解答・別解と自分の回答を見比べます。
4. 「正解」「不正解」「要復習」から自分で選びます。

## 複数の解答を登録する

文法ノートから問題を追加・編集し、英語と日本語の解答欄に1行につき1つずつ入力してください。最初の行が代表解答として扱われます。過去のバージョンで登録した別解も引き継がれます。

## 復習モード

不正解・要復習にした問題は、文法項目と出題方向ごとに復習リストへ追加されます。正解を2回連続で選ぶと復習リストから外れます。

## データ保存について

文法データと学習記録は、使用しているブラウザの `localStorage` に保存されます。同じ端末・同じブラウザで利用してください。ブラウザのデータを消すと履歴も消えるため、設定画面から定期的に JSON を書き出してください。
